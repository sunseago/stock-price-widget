# 股价悬浮窗（Stock Widget）

参考墨鱼阅读「悬浮迷你窗」交互做的桌面小工具：常驻桌面的半透明玻璃卡片，
实时显示股票价格与所在市场的交易状态。

- 支持 **A股 / 港股 / 美股 / 北交所**，随时切换标的
- 纯 Windows PowerShell + WinForms 实现，**免安装运行时**（只用系统自带组件）
- UI 与取数分离（子进程取数），界面永不卡顿
- 单文件 EXE 分发：双击即用

## 快速开始

**方式一（推荐）**：双击桌面快捷方式「股价悬浮窗」或 `dist\股价悬浮窗.exe`

**方式二（脚本，便于调试）**：
```powershell
powershell.exe -Sta -NoProfile -ExecutionPolicy Bypass -File PDD-Widget.ps1        # 联网行情
powershell.exe -Sta -NoProfile -ExecutionPolicy Bypass -File PDD-Widget.ps1 -Demo  # 演示数据(不联网)
```

## 界面与操作

```
 ┌──────────────────────────────────────────────┐
 │ 600519  贵州茅台                  [交易中]   │
 │ 1290.88 (红涨绿跌, 可切换)                   │
 │ 昨收 1309.30  今开 1305.01  最高 …  最低 …   │
```

| 操作 | 效果 |
|---|---|
| **鼠标悬停** | 窗口淡入至设定透明度 |
| **鼠标移开** | 自动淡出隐藏（默认至 5%，悬停可唤回） |
| **悬停时滚动滚轮** | 无级调节透明度（±5%/格，实时提示，防抖保存） |
| **左键拖动** | 移动窗口位置（松手即记忆） |
| **双击** | 浏览器打开东财对应市场行情页 |
| **右键菜单** | 立即刷新 / 打开行情页 / **切换股票**（19 个预设）/ 自动隐藏 / 置顶 / 透明度设置 / 纯透明模式 / 演示数据 / **开机自启动** / 退出 |

## 支持的股票代码

右键 → **切换股票** 直接选预设；或 右键 → 透明度设置 → 顶部「股票代码」自由输入（也可在右键设置里输入）：

| 市场 | 输入 | 示例 |
|---|---|---|
| A股（沪/深） | 6 位数字，可加 `sh`/`sz` | `600519`、`sz000001`、`300750` |
| A股（北交所） | 6 位数字，可加 `bj` | `430047` |
| 港股 | 4-5 位数字，可加 `hk` | `00700`、`hk09988` |
| 美股 | 字母代码，可加 `us` | `PDD`、`BABA`、`NVDA` |

切换后：行情源自动适配（腾讯 `sh/sz/bj/hk/us` 前缀、东财市场号、新浪 `gb_`/`sh`/`sz`）、
双击链接自动指向对应市场页面、成交额单位自动切换（元 / 港元 / 美元）、设置被记住。

## 功能说明

- **多源自动回退**：腾讯 → 东财 → 新浪，任一源成功即用；失败原因显示在卡片上。
- **交易状态徽章**：按各市场本地时间判断 `交易中 / 盘前 / 盘后 / 休市`
  - 美股：美东时间，含 NYSE 全天休市规则（元旦、MLK、总统日、耶稣受难日、阵亡将士、六月节、独立日、劳动节、感恩节、圣诞）
  - A股：北京时间 9:30–11:30 / 13:00–15:00，含 2026 法定节假日
  - 港股：北京时间 9:30–12:00 / 13:00–16:00，含 2026 公众假期
  - 注：**提前收盘**（如美股半日市、港股平安夜）未建模；节假日表**需每年更新**，见下文
- **透明模式**：右键可切换「玻璃卡片」与「纯透明（仅文字）」；透明度 20–100% 无级可调。
- **鼠标移开隐藏**：隐藏透明度默认 5%——**必须大于 0%** 才能再次被鼠标唤回。
- **配色**：默认红涨绿跌（A股习惯），可切换绿涨红跌。
- **启动先用缓存**：立即显示上次价格，再后台刷新，不会白屏。

### 内置性能设计

- 取数走独立子进程 + 临时文件回传，UI 线程不做网络 IO；取数超时（30s）自动结束子进程
- 每帧绘制涉及的 Brush / GraphicsPath / StringFormat 均**显式释放**，无 GDI 句柄泄漏
- 交易时段结果缓存 20 秒（避免每帧重算节假日表）
- 缓存写盘节流：仅当**代码变化 / 涨跌幅变化 ≥0.1 个百分点 / 超过 120 秒**才写 `lastQuote.json`
- **刷新频率动态化**：交易中按设定值（默认 6s），盘前 ≥20s，盘后 ≥30s，**休市 60s**
- 透明度滚轮 / 拖动位置采用**防抖保存**（停手约 0.7s 落盘），避免高频写盘

## 文件清单

| 文件 | 说明 |
|---|---|

| `PDD-Widget.ps1` | 主程序（悬浮窗 + 交互 + 设置 + 节假日表） |

## 常见问题

- **显示「获取失败·网络不可达」**：需要能访问 `qt.gtimg.cn` / `push2.eastmoney.com`
  （国内网络通常直连可用）。可右键 → 立即刷新重试。
- **开机自启**：右键菜单勾选「开机自启动」即可（在启动文件夹创建快捷方式，无需管理员权限）。
- **彻底退出**：右键 → 退出（悬浮窗不占任务栏）。
- **多显示器**：位置会按全部屏幕校验；副屏拔掉后会自动回到主屏右下角，不会飞到屏幕外。
- **节假日表更新**：内置 2026 年 A股（国务院办公厅通知）与港股（GovHK）假期。
  换年份后可在 `config\holidays.json` 覆盖，格式：
  ```json
  { "ASH": ["2027-01-01"], "HK": ["2027-01-01"] }
  ```
- **分发 EXE 给他人**：目标机器只需 Windows 10/11（自带 PowerShell 与 .NET Framework）。
  首次运行会把脚本释放到 `%LOCALAPPDATA%\PDDStockWidget`，配置也存于此（每用户独立、无需管理员）。
  未签名程序可能触发 SmartScreen 提示（选「更多信息 → 仍要运行」），个别杀软可能误报。
- **重新打包**（改完脚本后）：
  ```powershell
  csc /nologo /target:winexe /platform:anycpu /optimize+ /out:"dist\股价悬浮窗.exe" `
      /win32icon:"dist\app.ico" `
      /resource:"PDD-Widget.ps1,PDD-Widget.ps1" /resource:"PDD-Fetch.ps1,PDD-Fetch.ps1" `
      /r:System.dll /r:System.Core.dll dist\Launcher.cs dist\AssemblyInfo.cs
  ```
