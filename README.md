# 股价悬浮窗（Stock Widget）

参考墨鱼阅读「悬浮迷你窗」交互做的桌面小工具：常驻桌面的半透明玻璃卡片，
实时显示股票价格与所在市场的交易状态。

- 支持 **A股 / 港股 / 美股 / 北交所**，随时切换标的
- 纯 Windows PowerShell + WinForms 实现，**免安装运行时**（只用系统自带组件）
- UI 与取数分离（**常驻**取数子进程，界面永不卡顿），单文件 EXE 分发：双击即用
- 高 DPI 屏幕下按 Windows 缩放比例放大渲染，文字不发糊

## 快速开始

**方式一（推荐）**：双击桌面快捷方式「股价悬浮窗」或 `dist\股价悬浮窗.exe`

**方式二（脚本，便于调试）**：
```powershell
powershell.exe -Sta -NoProfile -ExecutionPolicy Bypass -File PDD-Widget.ps1        # 联网行情
powershell.exe -Sta -NoProfile -ExecutionPolicy Bypass -File PDD-Widget.ps1 -Demo  # 演示数据(不联网)
```

## 支持的股票代码

右键 → **切换股票** 直接选预设；也可在右键设置里输入代码：

| 市场 | 输入 | 示例 |
|---|---|---|
| A股（沪/深） | 6 位数字，可加 `sh`/`sz` | `600519`、`sz000001`、`300750` |
| A股（北交所） | 6 位数字，可加 `bj` | `920047`、`430047`、`830799` |
| 港股 | 4-5 位数字，可加 `hk` | `00700`、`hk09988` |
| 美股 | 字母代码，可加 `us` | `PDD`、`BABA`、`NVDA` |

交易所前缀按代码段推断（不再只看首位数字）：`6xxxxx`→沪、`920xxx`/`43xxxx`/`83xxxx`/`87xxxx`/`88xxxx`→北交所、
`9xxxxx`→沪B、其余→深市。切换后行情源自动适配（腾讯 `sh/sz/bj/hk/us` 前缀、东财市场号、新浪 `gb_`/`sh`/`sz`），
双击链接自动指向对应市场页面、成交额单位自动切换（沪B 按**美元**、深B 按**港元**、A股按元、港股按港元、美股按美元）、设置被记住。

## 功能说明

- **多源自动回退**：腾讯 → 东财 → 新浪（默认顺序，可用 `config.json` 的 `Source` 指定）；
  **粘性源**：上次成功的源下一轮排最前，少走弯路。任一源成功即用；失败原因显示在卡片上。
  - 新浪**不支持港股**（接口本身没有 `hk` 报价，会明确返回失败而不是给出错数据）
  - 美股东财价格按接口返回的小数位（`f59`）换算，不再按固定 2 位（曾导致价格放大 10 倍）
  - 新浪美股按接口实测字段位解析（`f[1]` 现价 / `f[4]` 涨跌额 / `f[2]` 涨跌幅 / `f[10]` 成交量）
  - **北交所老代码**（43/83/87/88 段且已切换/停用）若量额全 0，卡片会显示迁移告警，不把占位价当实时行情
- **交易状态徽章**：按各市场本地时间判断 `交易中 / 盘前(含竞价) / 午间休市 / 盘后 / 休市`
  - 美股：美东时间，含 NYSE 全天休市规则（元旦、MLK、总统日、耶稣受难日、阵亡将士、六月节、独立日、劳动节、感恩节、圣诞）
  - A股：北京时间 9:30–11:30 / 13:00–15:00，9:15–9:25 显示盘前竞价，11:30–13:00 显示午间休市；含 2026 法定节假日
  - 港股：北京时间 9:30–12:00 / 13:00–16:00，9:00–9:30 显示盘前竞价；含 2026 公众假期
  - 注：**提前收盘**（如美股半日市、港股平安夜）未建模；节假日表**需每年更新**，见下文
- **透明模式**：右键可切换「玻璃卡片」与「纯透明（仅文字）」；透明度 20–100% 无级可调。
- **鼠标移开隐藏**：隐藏透明度默认 5%——**必须大于 0%** 才能再次被鼠标唤回。
- **配色**：默认红涨绿跌（A股习惯），可切换绿涨红跌。
- **启动先用缓存**：立即显示上次价格，再后台刷新，不会白屏；缓存超过一个刷新周期时 footer 显示「N 分钟前」。
- **数字格式固定不变**：千分位/小数点按不变文化输出，系统区域设成德/法等（逗号小数点）也照样显示 `1,435.26`。

### 内置性能设计

- 取数走**常驻**子进程（`PDD-Fetch.ps1 -Serve`，一行命令经 stdin 传入），复用 HTTP 连接池：
  第 1 轮约 0.9 s（含 TLS 握手），之后每轮约 **0.34 s**（实测）；相比每次刷新 fork 一个
  `powershell.exe`（单轮 0.87–1.35 s，其中空启动就 0.36–0.43 s，每天约 1.4 万次进程创建）显著省资源
- 子进程异常/超时会自动重建；重建失败退回一次性取数，不会白屏
- **重绘节流**：悬停定时器 400 ms，只在「内容版本号变了」时重绘；淡入动画结束后停表（空闲 CPU 实测 ~1.5%）
- 每帧绘制涉及的 Brush / GraphicsPath / StringFormat 均**显式释放**，无 GDI 句柄泄漏
- 交易时段结果缓存 20 秒（避免每帧重算节假日表）
- 缓存写盘节流：仅当**代码变化 / 涨跌幅变化 ≥0.1 个百分点 / 超过 120 秒**才写 `lastQuote.json`；JSON 原子写（`.tmp` → `Replace`），不会读到半截文件
- **刷新频率动态化**：交易中按设定值（默认 6s），盘前 ≥20s，盘后 ≥30s，**休市 60s**
- 透明度滚轮 / 拖动位置采用**防抖保存**（停手约 0.7s 落盘），避免高频写盘

## 文件清单

| 文件 | 说明 |
|---|---|
| `dist\股价悬浮窗.exe` | **分发用的单文件程序**（内嵌下面两个脚本，双击即用）；仓库内这份仍是 1.2.0.0 旧构建，需按「重新打包」生成 1.3.0.0 |
| `PDD-Widget.ps1` | 主程序（悬浮窗 + 交互 + 设置 + 节假日表） |
| `PDD-Fetch.ps1` | 取数进程（腾讯/东财/新浪，三市场 + 北交所；支持 `-Serve` 常驻模式） |
| `PDD-Widget.vbs` | 静默启动包装（脚本模式下开机自启用，无控制台窗口） |
| `src\Launcher.cs` | EXE 启动器源码（释放脚本 → 静默启动，并传 `PDDWIDGET_EXE`） |
| `src\AssemblyInfo.cs` | EXE 版本信息（1.3.0.0） |
| `src\app.ico` | EXE 图标（当前只有 64×64 单尺寸） |
| `tests\Test-Widget.ps1` | 自检脚本：断言 + 离屏渲染（不需要 Pester） |
| `config\config.json` | 设置记忆（股票/位置/透明度/源/刷新间隔等），首次运行自动生成 |
| `config\lastQuote.json` | 最近行情缓存（节流写入） |
| `config\trace.log` | 运行日志（启动诊断与异常，排查用） |
| `config\holidays.json` | **可选**：自定义节假日表，覆盖内置 2026 表 |

> 配置目录位置：**脚本模式**在脚本所在目录的 `config\`（便于携带调试）；
> **EXE 模式**在 `%LOCALAPPDATA%\PDDStockWidget\config\`（每用户独立、无需管理员）。
> README 早前写成 `%APPDATA%` 与实际不符，已更正。

## 常见问题

- **显示「获取失败」**：需要能访问 `qt.gtimg.cn` / `push2.eastmoney.com` / `hq.sinajs.cn`
  （国内网络通常直连可用）。错误行会写出各源的失败原因，可右键 → 立即刷新重试。
- **开机自启**：右键菜单勾选「开机自启动」即可（在启动文件夹创建快捷方式，无需管理员权限）。
- **彻底退出**：右键 → 退出（悬浮窗不占任务栏）。
- **多显示器**：位置会按全部屏幕校验；副屏拔掉后会自动回到主屏右下角，不会飞到屏幕外。
- **高 DPI**：程序启动时自行声明 DPI 感知并按系统缩放比例放大几何与字号；125%/150% 下不再整卡拉伸。
- **节假日表更新**：内置 2026 年 A股（国务院办公厅通知）与港股（GovHK）假期。
  换年份后可在 `config\holidays.json` 覆盖，格式：
  ```json
  { "ASH": ["2027-01-01"], "HK": ["2027-01-01"] }
  ```
  未覆盖当年时，卡片 footer 会提示「假期表未覆盖 YYYY, 仅按时间判断」，不再凭旧表谎称「交易中」。
- **分发 EXE 给他人**：目标机器只需 Windows 10/11（自带 PowerShell 与 .NET Framework）。
  首次运行会把脚本释放到 `%LOCALAPPDATA%\PDDStockWidget`，配置也存于此（每用户独立、无需管理员）。
  未签名程序可能触发 SmartScreen 提示（选「更多信息 → 仍要运行」），个别杀软可能误报。
- **重新打包**（改完脚本后，在仓库根目录执行；`csc` 来自 .NET Framework 自带编译器）：
  ```powershell
  csc /nologo /target:winexe /platform:anycpu /optimize+ /out:"dist\股价悬浮窗.exe" `
      /win32icon:"src\app.ico" `
      /resource:"PDD-Widget.ps1,PDD-Widget.ps1" /resource:"PDD-Fetch.ps1,PDD-Fetch.ps1" `
      /r:System.dll /r:System.Core.dll src\Launcher.cs src\AssemblyInfo.cs
  ```

## 已知限制

- 5% 半透明状态下仍然吃鼠标事件（**无点击穿透**），悬停会挡住底下窗口的操作
- 图标只有 64×64 单尺寸，任务栏/高分屏下可能偏糊
- 无 CI、无自动构建产物发布；`dist\` 内重复的旧副本已删除，只剩 `股价悬浮窗.exe`
- 仓库内的 `dist\股价悬浮窗.exe` 为 **1.2.0.0 旧构建**（不含 1.3.0.0 的修复）：本机已用 1.3.0.0 脚本重新打包，
  但二进制无法经接口上传，请按上文「重新打包」命令在本机覆盖后自行提交
